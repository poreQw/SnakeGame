# NEON SNAKE 🐍

10대 취향 저격(?) 네온 스타일의 심플한 스네이크 게임.
빌드 도구나 설치 없이 **`index.html` 하나**로 바로 실행됩니다.

## 실행

- `index.html` 파일을 더블 클릭
- 또는 터미널에서:

```powershell
start index.html
```

첫 방문 시에는 게임의 **자기소개 인트로**가 한 번 표시됩니다.
버튼 또는 `Space` / `Enter` 로 시작하면 다시 표시되지 않으며, 이후에는 바로 메뉴가 나옵니다.
처음 플레이하는 경우 인트로 또는 메뉴에서 **게임 방법 배우기**를 선택하면 이동, 먹이와 콤보, 몬스터와 충돌 규칙을 단계별로 익힐 수 있습니다.

## 조작

| 동작 | 키 / 입력 |
| --- | --- |
| 이동 | 방향키, `WASD`, 모바일 스와이프, 하단 D-pad |
| 시작 / 일시정지 | `Space`, `Enter` |
| 일시정지 | `Esc`, `P` |
| 설정 / 도우미 | 메뉴의 🐱 버튼 |

## 게임 규칙

- 네온 사탕(이모지 먹이)을 먹으면 점수가 오르고 몸이 길어집니다.
- 자기 몸에 부딪히면 몸이 한 칸 줄고 게임은 계속됩니다. 벽에 닿으면 게임 오버.
- 100점부터 몬스터가 나타나며, 몬스터에 부딪혀도 몸이 한 칸 줄어듭니다. 점수가 100점 오를 때마다 몬스터가 추가로 등장하며 최대 3마리까지 나옵니다.
- 2.6초 안에 연속으로 먹으면 **콤보**가 쌓여 최대 `x5` (한 번에 50점).
- 점수가 오를수록 레벨이 올라가고 속도가 빨라집니다.
- 최고 점수는 브라우저(`localStorage`)에 저장됩니다.

## 고양이 도우미 🐱

메뉴 / 일시정지 / 게임오버 화면에 나타나는 **🐱 고양이 도우미 / 설정** 버튼으로 엽니다.
게임 로직과 분리된 추가 모듈이라 기존 동작에는 영향을 주지 않습니다.
고양이는 두꺼운 검정 손그림 선화 SVG로 그려지며, 기분에 따라 눈과 입 부품이 바뀝니다.

- **같이 반응하기** — 먹이 섭취, 콤보, 레벨업, 몬스터 등장, 게임오버, 신기록 순간에 고양이가 표정을 바꾸며 한마디씩 합니다. (윙크 / 웃음 / 사랑 / 능글 / 놀람 / 시무룩)
- **실시간 공략 팁** — 80점 부근에서 몬스터 등장 경고, 100점마다 몬스터 추가 경고, 그 밖의 상황별 조언을 주기적으로 띄웁니다.
- **설정 메뉴** — 도우미 켜기/끄기, 수다 정도(조용/보통/수다쟁이), D-pad 표시 여부, 효과음. 모두 `localStorage`에 저장됩니다.

## 특징

- 네온 글로우 그래픽, 파티클, 화면 흔들림 효과
- 페이지 첫 진입 시 제목, 점수 카드, 게임 보드가 순차적으로 나타나는 애니메이션
- 이모지 먹이 6종 (🍩 🍕 🧋 🍓 💎 ⭐)
- WebAudio로 만드는 사운드 (외부 음원 파일 없음) + 음소거 버튼
- 모바일 진동, 터치 D-pad, 스와이프 조작
- 🐱 고양이 도우미 — 말풍선 반응, 실시간 공략 팁, 설정 메뉴
- 외부 라이브러리 / 네트워크 의존성 없음

## 프로젝트 소개 PPT

게임 페이지를 열 때마다 한국어 프로젝트 소개가 자동으로 표시되며, 게임 화면 왼쪽 아래의 작은 📘 원형 버튼으로 다시 열 수도 있습니다. 소개 첫 장은 아침, 플레이 경험은 오후, 게임 설계는 저녁 풍경으로 바뀝니다. 하얀 별은 저녁에만 보이고, 노란 반짝이는 아침과 오후에 보이지 않습니다. 아침에는 노란 반짝이 자리에 태양이 있고, 태양은 오후에도 보이다 저녁에는 풀숲으로 바뀝니다. 달은 아침과 저녁에 보이고 오후에는 사라집니다. 천체는 **다음 내용**을 눌러도 움직이지 않습니다. 뱀이 길을 따라 움직이고, 소개 항목도 내용에 맞는 그림과 함께 한 장면씩 바뀝니다. 새 장면이 나오면 직전 장면은 사라집니다. 원본 PPT도 뷰어 안에서 다운로드할 수 있습니다.
